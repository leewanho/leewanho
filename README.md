## What I build | 제가 만드는 것

- **Problem discovery** — 사용자와 도메인 맥락에서 해결할 문제를 찾고 우선순위를 정합니다.
- **Product & model design** — 요구사항을 제품 흐름, 데이터, 모델 평가 기준으로 구체화합니다.
- **End-to-end delivery** — AI 모델부터 API·웹 인터페이스까지, 검증 가능한 제품으로 구현합니다.

## Selected work | 대표 프로젝트

### 🏆 [FOOK — 혈액투석 환자 맞춤형 AI 식단 관리](https://github.com/leewanho/FOOK)
**장관상 수상작 · Ministerial Award-winning project**

투석 환자의 개인별 영양 기준을 바탕으로 한 끼 식단을 생성하고, 기준을 벗어나면 재료 단위까지 재조정하는 AI 식단 관리 서비스입니다.

**Problem definition** 환자별 영양 제약을 실제 식사 선택으로 연결  
**Solution** Seq2Seq + Attention, REINFORCE, FastAPI, React, PostgreSQL  
[Service](https://fook-omega.vercel.app) · [Repository](https://github.com/leewanho/FOOK)

### 🩺 [Atom — 아토피 케어 서비스](https://github.com/leewanho/Atom)
**Team project · 팀 프로젝트**

아토피 환자의 관리 경험을 개선하기 위해 기획·구현한 팀 프로젝트입니다. 사용자 문제를 제품 기능과 AI 활용 가능성으로 풀어내는 협업 경험을 담았습니다.

**Focus** Health-care user experience · Team delivery  
[Service](https://atocatch.streamlit.app/) · [Repository](https://github.com/leewanho/Atom)

### 📝 [Ambient Clinical Documentation LLM](https://github.com/leewanho/Ambient-Clinical-Documentation-LLM)
**Clinical conversation → structured documentation**

진료 대화를 구조화된 임상 문서로 전환하는 자동화 연구·프로토타입입니다. MEDIQA-Chat 2023 재현을 출발점으로 한국어 확장과 다중 LLM 평가를 수행했습니다.

**Focus** Documentation automation · Korean expansion · Evaluation design  
[Repository](https://github.com/leewanho/Ambient-Clinical-Documentation-LLM)
